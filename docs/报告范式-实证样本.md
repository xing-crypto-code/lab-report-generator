> 来源：用户 2026-10 提交的《组合逻辑电路》实验报告（实验二）实际成品 + 老师空白模板。
> 这是**已通过的真实范式**，生成时应照此结构。本文件是"从真实样本学到的数据库"。

## 一、页面与表格版式（老师模板实测值，不可改）

- 页面 A4 21×29.7 cm，边距 上/下 2.54，左 **1.75**，右 **2.00**

- 两张表：信息表 2×5（班级/学号/姓名/实验日期/成绩）、主表 7×6

  1. 课程名称 | 实验名称 | 指导教师
  2. 实验目的
  3. 实验仪器
  4. 实验原理
  5. **实验过程（可另附页）** ← 整行合并单元格，内容最多
  6. 实验小结 与建议

- 大标题「成都大学实验报告」宋体 22pt 加粗居中

## 三、实验过程栏的标准内部结构（最重要）

一个合并单元格内，依次为四大块：

```
一、实验步骤
1. ...（6 条左右，含"测试完毕先断电再拆线"这类收尾）
2. ...

【此处插入实验接线图】        ← 虚线占位框

二、实验数据记录与分析
（引言一句：按 XX 定义，理论输出如下表，实测列留待填入）
[真值表：输入列 + 理论输出列 + 实测现象列（实测留空或已填）]
数据处理：...（换算/判读规则一句）

逻辑推导与验证：
1. S＝A′B＋AB′＝((A′B)′·(AB′)′)′＝…
2. C＝AB＝((AB)′)′＝…
3. 逐门核对：门 1 输入 A、B，输出 (AB)′；门 2 …；四组输入代入均与真值表一致。

三、误差分析
（结合本次实际器件与接线写 3~5 条：器件电平离散、输入悬空、接触电阻、
LED 限流电阻判读、门延迟竞争冒险 …）

四、思考题
1. 题目？
   答：...
2. 题目？
   答：...
3. 题目？
   答：...
```

> 关键：**误差分析与思考题是"实验过程"栏内的小标题，不是顶层章节**。
> 顶层只有「实验目的 / 实验仪器 / 实验原理 / 实验过程 / 实验小结」这五栏。

## 四、各栏写法要点

### 实验目的
直接照抄指导书，`1. 2. 3.` 分条，每条一句，动词开头（学习 / 了解 / 掌握）。

**实证原文**：
```
1. 学习组合逻辑电路的设计方法。
2. 了解组合逻辑电路中竞争冒险的分析和消除方法。
3. 掌握组合逻辑电路的调试方法。
```

### 实验仪器
照抄指导书，`1. 2. 3.` 分条，只列本次实际使用的，不补充指导书没有的。

**实证原文**：`1. 实验箱  2. 示波器  3. 信号发生器  4. 万用表`

### 实验原理
- 先写功能定义："组合逻辑电路的输出只由当时的输入决定，与电路过去的状态无关，
  因此没有记忆性。电路由各种门电路连接而成，连接中不存在反馈线。"
- 再写设计/分析步骤，`1. 2. 3.` 分条
- 再落到本次具体电路（"本次用 74LS00 二输入四与非门实现半加器…"），给真值表与最小项表达式
- 再给与非-与非变换过程（摩根定律，逐步等式）
- 竞争冒险等概念按需补一段
- **公式逐行单独成行、顶格**，编号统一 `1. 2. 3.`

### 实验小结
一段话收尾，写实际结论（"实测现象与理论输出一致，说明由真值表化简到
与非-与非式再接线的方法是正确的"），可带一点接线/调试体会。
**不要写"通过本次实验加深了理解"这类套话。**

## 五、思考题的写法（实证）

- 编号 `1. 2. 3.` **连续递增**（不要每条都写 `1.`——这是本样本里的实际错误）
- 每题"题目"一行，下一行以 `答：` 开头
- 答案 2~4 句，要有具体依据，不是空泛结论

**典型题库**（本样本实测）：
1. 组合逻辑电路与时序逻辑电路的根本区别是什么？
2. 竞争冒险产生的原因是什么？如何消除？
3. 用与非门实现半加器时，为什么进位 C 要用两级与非门？

参考答案要点：
- 组合：输出只取决于当前输入，无记忆性，无反馈；时序：输出还与电路原状态有关，
  含存储元件和反馈。
- 竞争冒险：门存在传输延迟，两输入同时向相反方向变化时不同路径延迟不同，
  输出出现干扰脉冲。消除：接入滤波电容 / 增加冗余项 / 采用格雷码等可靠性编码 /
  引入封锁或选通脉冲。
- C＝AB 需先取反再取反，即 (AB)′′，故用两个与非门（第二个接成反相器）。

## 六、图片与图表

- 接线图 / 电路图用 `【此处插入实验接线图】` 占位（渲染为灰虚线框），学生后续贴图
- 真值表用 Markdown 表格 → 转 Word 嵌套表格，表头加粗、内容居中
- 拍照贴的电路图要**白底、等比缩放**（常用宽 15 cm）

## 七、易错点（本样本中实际出现的）

1. **思考题每条都写 `1.`** 而不是 1./2./3. —— 编号必须连续递增
2. 「逻辑电路图 2逻辑电路图 2」这类**重复残留标题** —— 生成时不得出现
3. 信息表残留 `tblpX=-30` 导致比主表**左偏 30 dxa** —— 两张表必须都 `tblpX=0`
