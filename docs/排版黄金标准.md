# 排版黄金标准（用户已确认的版式）

> 这份文档记录**用户明确认可的那一版排版**。任何改动都必须先跑
> `python tests/test_golden_layout.py` 全部通过，否则就是偏离了标准。

## 一、页面与版心

| 项 | 值 |
|---|---|
| 页面 | A4 21.0 × 29.7 cm |
| 边距 | 上/下 2.54 cm，左 **1.75** cm，右 **2.00** cm |
| 版心宽 | **9780 dxa** |
| 版心左右边界（绝对） | 左 **993** / 右 **10773** |

## 二、表格（两张表必须严格重合）

所有顶层表格（顶部信息表、主表）必须满足：

- `tblLayout = fixed` —— autofit 会让 Word 忽略设定列宽、边框随内容漂移
- `tblW == ΣgridCols == ΣtcW == 9780` —— 三者必须相等
- `tblpPr` 锚点 `horzAnchor=margin`、`tblpX=0` —— 全部贴版心左边缘
- **无** `w:jc`（不能居中、不能右对齐）
- 单元格边距：左右 **108** dxa、上下 **0**
- 结果：两表左边界都是 993、右边界都是 10773，**上下边框完全重合**

## 三、字体 / 字号 / 行距 / 字间距

| 项目 | 标题 | 正文 |
|---|---|---|
| 字体 | 宋体（ascii/hAnsi/eastAsia/cs 全设） | 同左 |
| 字号 | **14 pt（四号）** | **12 pt（小四）** |
| 加粗 | **加粗** | **不加粗** |
| 行距 | **固定值 18 pt**（`lineRule=exact`） | 同左 |
| 字间距 | **-4 twips** | **-6 twips** |
| 首行缩进 | 0 | 2 字符（24 pt） |
| 段前/段后 | 10 pt / 4 pt | 0 / 0 |

**必须覆盖全部段落**，包括模板原有的 label 格（课程名称、实验目的、
实验仪器、实验原理、实验小结、教师评阅…）。这些 label 格如果漏了，
会表现为 **label 列与内容列上下对不齐**——这是用户反复反馈过的问题。

## 四、编号

- 统一为 `1. 2. 3.`（阿拉伯数字 + 英文句点 + 一个空格）
- **禁止混用**：`2、` `（3）` `④` `a.` 这些写法一律归一成 `1.`
- 同一编号串内从 1 连续递增，每个小标题/表格后重新起 1
- 说明性前言（`数据处理：` `74LS00 与非门：` 等以冒号结尾的行）不加编号

## 五、段落结构

- `w:pPr` 子元素顺序合法（`pStyle→…→snapToGrid→spacing→ind→jc→…→rPr`）
- `w:rPr` 子元素顺序合法（`rFonts→b→…→spacing→…→sz`）
- **顺序错了 Word 会静默忽略**，表现为行距/缩进不生效、上下不对齐
- 有内容的单元格**不留尾部空段**（否则编辑时按 Delete 会吃掉上一行）
- 无异常首行缩进（`firstLineChars > 10` 一律视为脏数据清除）

## 六、内容结构

- 主表 **7 行**：课程名称/实验名称/指导教师、实验目的、实验仪器、
  实验原理、实验过程（可另附页）、实验小结与建议、教师评阅意见及建议
- **不得产生模板外的顶层章节**（如"实验设计""思考题"要写进实验过程内部）
- 实验目的 / 实验仪器：**照抄指导书原文**，不增删、不改写
- 图片位置用 `【此处插入实验接线图】` 渲染成灰色虚线框

## 七、验收方式

```powershell
# 黄金标准（版式）
python tests/test_golden_layout.py

# 模板固化（8 条 fix）
python tests/test_template.py
```

两套都必须 `✓ 全部通过`。

## 八、变更纪律

改动 `modules/generator.py` 的排版相关代码后：

1. 先跑两套测试，确认没破坏黄金标准；
2. 如果确实需要改标准（用户提出新的版式要求），**先改本文件 + 改测试基线**，
   再改代码，避免"代码改了但标准没跟上"；
3. 改动涉及模板本身结构的，按 `docs/模板固化规范.md` 登记 `fix_NN` 并重新烘焙。
