# 实验报告写作规范（成都大学 · 电子技术基础实验）

本规范来自多轮实际修改（模电实验 1–7、数电实验 2–5）沉淀，**必须照做**，不要临场发挥版式。

## 0. 先决条件

- 模板与格式**只能克隆母版**：`实验7/数电实验1.docx`（成都大学实验报告母版，7 行主表）。不要从 `Document()` 重建。
- 学生信息固定：学生信息自己填写。**实验日期留空**（除非用户已填）。
- 用 `python-docx` 改，用 Word 导出 PDF 再转 PNG 逐页核对。

## 1. 版式参数（母版实测值，不要改）

| 项 | 值 |
|---|---|
| 页面 | A4 21×29.7 cm |
| 边距 | 上/下 2.54 cm，左 1.75 cm，右 2.00 cm |
| 大标题 | 「成都大学实验报告」宋体 22 pt 加粗居中 |
| 主表 | 7 行 × 6 列：课程名称 / 实验目的 / 实验仪器 / 实验原理 / 实验过程（可另附页）/ 实验小结与建议 / 教师评阅意见及建议 |
| 正文 | 宋体 12 pt（`w:sz` 半磅值 `24`），必须设 `w:eastAsia` |
| 顶部信息表 | 2 行 × 5 列（班级/学号/姓名/实验日期/成绩） |
| 主表定位 | 保留 `w:tblpPr`：`horzAnchor="page" tblpX="1157"`。**删掉浮动定位会让主表比信息表左移 25 px，边框错位** |

宽度基准（像素，页面渲染宽 1860 px 时）：信息表与主表左右边框应分别为 **163 / 1673**。改动后用像素扫描校验。

## 2. 表格列宽必须写进 tblGrid

```python
grid = tbl.find(qn('w:tblGrid'))
for gc in grid.findall(qn('w:gridCol')): grid.remove(gc)
for w in widths:
    gc = OxmlElement('w:gridCol'); gc.set(qn('w:w'), str(w)); grid.append(gc)
```

只设单元格 `w:tcW`、不设 `gridCol`，Word 会按**等宽重排**，表现为“表格错位/列宽不对”。同时设 `tblW = sum(widths)`（`type=dxa`）。

- 单元格内可用宽度 ≈ **9448 dxa**，表格总宽 ≤ **9100 dxa**，超出按比例缩。
- 嵌套表居中时，把包装单元格 `w:tcMar` 左右设为 0，否则内容整体偏移 108 dxa。

## 3. 编号：三级、全自动

格式固定三级：`一、` / `1.` / `1）`。

**必须用 Word 自动编号**（`w:numPr`），不手打。手打编号删条后不会重排。

- 编号定义写进 `numbering.xml`：`w:abstractNum`（`lvlText` 为 `%1、` / `%1.` / `%1）`，`numFmt` 中文数字用 `chineseCountingThousand`）＋若干 `w:num` 指向它，`w:lvlOverride/w:startOverride=1` 让每套从 1 开始。
- **每套独立序列**：实验目的、实验仪器、实验原理各一条；实验过程内每个一级标题下的 `1.` 各一条；`1）` 一条。否则编号会跨栏目连号。
- 段落侧：删掉显式 `w:ind`，缩进交给编号定义的 `w:lvl/w:pPr/w:ind`。

| 层级 | 编号位置 | 正文/换行 |
|---|---|---|
| 一、 | 0（顶格） | 紧接（`w:suff=nothing`） |
| 1.（目的/仪器/原理格） | 0 | 360 dxa（18 pt） |
| 1.（实验过程内） | 480 dxa（24 pt） | 720 dxa（36 pt） |
| 1） | 960 dxa（48 pt） | 1320 dxa（66 pt） |

正文段与所属层级的正文列对齐；行文中的并列说明（“（1）…（2）…”）保持括号形式，**不要**改成编号。

## 4. 各栏写什么

- **实验目的 / 实验仪器**：照指导书，仪器只列本次**实际使用**的器件。
- **实验原理**：概念、分析方法、设计方法、本实验电路的定量关系。只写与本次器件相关的内容。
- **实验过程**（一个单元格内，依次）：
  1. `一、实验步骤` —— 只保留本次实验相关的步骤（用 74LS00 就删掉 74LS20/74LS138/四变量/险象等）。
  2. `二、实验数据记录与分析` —— 真值表 → 最小项表达式 → 卡诺图化简 → 与非—与非变换 → 逻辑图 → 逐门验证 → 门数说明 → 接线验证 → 误差分析 → 结论。
  3. `三、思考题` —— 题目 + 解答。
  4. 需要时 `四、设计实验` —— 题目 + 留空段供学生贴图。
- **推导要详细**：分步写、每步说明依据（摩根定律、卡诺图相邻性等），并补“逐门验证”（四组输入代入门级表达式核对真值表）与“为什么需要 N 个门”的论证。
- **实验小结**：只写实际做过的事，不出现与正文不符的“用某某器件实现了某某”。
- 公式用中文标点：`S＝A′B＋AB′`、`UCEQ＝UCQ－UEQ`。

## 5. 图表

- **题注在下方居中**（表题在表下、图题在图下），五号 10.5 pt，编号 `表3.2-1` / `图3.2-2`，按出现顺序编。
- **表格不能跨页拆开**：把表放进 1×1 无边框容器表，容器行设 `w:cantSplit`，Word 只能整块换页。
  - `w:trPr` 子元素顺序敏感：`cantSplit` 必须排在 `trHeight` 之前，`tblHeader` 排第一；顺序错 Word 静默忽略。
- 单元格内的**手动分页符无效**（`w:br type="page"`、`pageBreakBefore` 都会被忽略），只能靠 `cantSplit`。
- 图片：白底、等比缩放（常用宽 15 cm），原图压到约 1600 px 再插入，否则文档很大。

## 6. 数据填写

- **所有实测值单元格留空**，由学生填写。
- 已知条件预填（如 `Ui＝4mV`、`RL＝∞/5.1kΩ`、激励幅值、真值表输入列）。
- 每张表下加一句 `数据处理：…`，写清换算公式。

## 7. 常见坑（都踩过）

1. 单元格段落带 `w:framePr`（浮动图文框）＋`w:spacing line="40" exact` → 显示为**删不掉的小黑点**，需删除该空段。
2. 表格后多余的极矮空段落 → **多出空白页**，把末尾空段压到 1 pt 行高（`w:line=20 exact`、`rPr/sz=2`）。
3. 中文路径传给 Word COM 报“找不到文件”（ANSI 编码）→ 先把 docx 复制到纯英文临时路径再导出。
4. `render_pages` 的 WinRT 调用：`IAsyncAction` 与 `IAsyncOperation` 要分开 `await`。
5. Word COM `SaveAs` 偶发挂起 → 改用 `ExportAsFixedFormat(pdf, 17)`，并先 `Stop-Process WINWORD` 清理残留进程。
6. 并行脚本误删内容 → 每次改动前备份，改后**逐段比对全文**。

## 8. 工作流程（每次都必须走完）

0. **切换实验报告时先复盘**（切到另一份实验报告之前必做）
   在动手改新报告之前，先用一小段话总结**上一份报告这轮改了什么**，至少覆盖：
   - **排版**：页面/边距、主表定位、缩进（哪几级、各多少 dxa）、行距、段间距
   - **格式**：编号体系（是否自动、序列怎么分）、字体字号、加粗规则
   - **内容结构**：各栏顺序、推导写到哪一步、哪些内容被删/被合并
   - **图表**：题注位置与编号、表格宽度处理、图片尺寸与白底处理
   - **本次要沿用的 / 要改变的**：明确列出“沿用前一份的哪些做法、这一份需要额外注意什么”

   复盘之后再看新报告的实际结构，确认差异（例如模电用「实验电路」、数电用「实验内容与逻辑关系」），再开始改。**不要跳过复盘直接上手**，否则容易把上一份的习惯错套到这一份。

1. **备份**：复制一份到临时目录，文件名带“改前”。
2. **结构勘察**：先 dump 目标单元格的子元素（段落/表格/图片）与 `pPr`（`ind`、`spacing`、`numPr`），确认再动手。
3. **改动**：只动要求的范围；用户已手工修改的内容一律不碰。
4. **渲染核对**：Word 导出 PDF → 拆页 PNG → 逐页看。
5. **量化校验**：
   - 对齐：像素扫描竖线位置（应为 163 / 1673），或 Word COM 读 `LeftIndent / FirstLineIndent`。
   - 内容：按段落全文比对，确认“零丢失、零改写”。
   - 图片：`len(d.element.body.findall('.//w:drawing'))` 数目对得上。
6. **交付**：说明改了什么、没动什么、备份在哪、页数。

## 9. 常用代码骨架

```python
from docx import Document
from docx.table import _Cell
from docx.shared import Cm, Pt
from docx.enum.text import WD_ALIGN_PARAGRAPH
from docx.oxml import OxmlElement
from docx.oxml.ns import qn

doc = Document(template)          # 克隆母版
tbl = doc.tables[1]               # 主表
cell = _Cell(tbl.rows[4]._tr.tc_lst[0], tbl)   # 实验过程单元格

def clear_cell(cell):
    for ch in list(cell._tc):
        if ch.tag != qn('w:tcPr'):
            cell._tc.remove(ch)

def style_run(r, size=12, bold=False):
    r.font.size = Pt(size); r.bold = bold
    r._element.rPr.rFonts.set(qn('w:eastAsia'), '宋体')
```
