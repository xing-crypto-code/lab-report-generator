# 模板固化规范（每修一个排版 bug 都按此流程）

> 约定：**以后每修复一个排版/边框类 bug，都必须把修复固化进内置模板文件本身**，
> 而不是只在代码里临时打补丁。模板永远是最新状态。

## 为什么

内置模板 `templates/内置实验报告模板.docx` 是所有无模板用户的默认线框。
如果修复只写在 `modules/generator.py` 的运行时补丁里，模板文件本身仍是旧的，
下次有人直接拿模板当母版、或修复被重构掉，问题就会复发。

## 三步流程

### 第 1 步：在 `modules/template_fix.py` 登记修复

在 `TEMPLATE_FIXES` 列表里追加一条：

```python
TEMPLATE_FIXES = [
    ...,
    ("fix_06_your_fix_name", "一句话说明修的是什么", fix_06_your_fix_name),
]
```

同时写对应的 `fix_06_your_fix_name(doc)` 函数，入参是 `Document` 对象，
返回「改动了多少处」（整数），方便看日志。

### 第 2 步：重新烘焙模板

```powershell
python -X utf8 temp\_run_rebake.py
```

（内部调用 `rebake_template('templates/内置实验报告模板.docx')`）

脚本会：
- 自动备份到 `.bak`（首次）
- 依次跑 `TEMPLATE_FIXES` 里**全部**修复（幂等，可反复跑）
- 跑 `verify_template()` 校验，打印问题清单

**注意**：模板文件若是只读会报 `PermissionError`，先执行：

```powershell
attrib -R "templates\内置实验报告模板.docx"
```
并先停掉 7860 端口的服务（它可能持有文件句柄）。

### 第 3 步：补回归断言

在 `tests/test_template.py` 里加对应的 `check(...)`，然后跑：

```powershell
python -X utf8 tests\test_template.py
```

必须全部通过才算固化完成。

## 自动兜底

`app.py` 在每次使用内置模板生成前会调 `verify_template()`；
若发现未固化的问题，**会自动就地烘焙**并在日志里提示：

```
🔧 内置模板有 N 处未固化，正在自动烘焙…
✓ 模板已烘焙到最新版
```

所以即使忘了手动跑，运行时也会自愈。

## 相关代码中的运行时对齐（不写进模板的部分）

嵌套表格（真值表、虚线占位框）是在**生成时**插入的，无法预先固化到模板里，
由 `modules/generator.py` 的 `_stretch_table_full_width()` 保证：

- `tblW == ΣgridCols == (父单元格 tcW − 左边距 − 右边距)`
- `tblInd = −左边距`（把表格左边界顶到单元格内框，抵消默认 108 dxa 偏移）
- 不设 `jc`（左对齐）
- `tblLayout = fixed`

这三条缺任何一个，嵌套表就会与主表边框错开一条线。
